# License Studio

**License Studio** は、創作物・Creative Commons・ソフトウェア向けライセンスを、**人が読みやすいA4 PDF**としてまとめるブラウザアプリです。

GitHubの `LICENSE` ファイルだけを作るツールではなく、イラスト、3Dモデル、BGM、動画、ゲーム素材、キャラクター、同人作品などを配布するときの「利用条件そのもの」を見やすく伝えることを目的にしています。

## 特徴

- GitHub Pagesで動く、ビルド不要の静的アプリ
- PDFプレビューを見ながら編集
- PDFはA4・複数ページ対応
- 表紙画像をアップロード可能
- 5種類のデザインテーマ
- 自由なアクセントカラー
- 日本語 / English / 日英併記
- ブラウザ内へ設定を自動保存
- 設定をJSONとしてバックアップ・復元

## 3つのモード

### 1. カスタム規約

創作物向けの独自利用条件を作ります。

用途ごとに次の3段階を指定できます。

- 許可
- 要相談
- 禁止

対象項目:

- 個人利用
- 商用利用
- 収益化コンテンツ
- 改変・加工
- 作品への組み込み
- 依頼・受託制作
- グッズ・商品化
- 素材の再配布

さらに、クレジット、同条件での継承、素材抽出禁止、AI学習、成人向け、政治・宗教、NFT、なりすまし等の条件を指定できます。

用途別プリセットも用意しています。

- クリエイター向け標準
- オープン素材寄り
- 素材販売向け
- BGM・音声素材向け
- キャラクター利用向け
- 許可制・厳格

独自条項も自由に追加できます。

### 2. Creative Commons

以下のCreative Commons 4.0系ライセンスとCC0に対応します。

- CC BY 4.0
- CC BY-SA 4.0
- CC BY-ND 4.0
- CC BY-NC 4.0
- CC BY-NC-SA 4.0
- CC BY-NC-ND 4.0
- CC0 1.0

「商用利用を許可するか」「改変作品の共有を許可するか」から適切なCCライセンスを選択できます。

Creative Commonsの標準ライセンス本文自体は変更せず、PDFは利用者向けの分かりやすい案内として生成します。

### 3. ソフトウェアライセンス

代表的なOSSライセンスの、人が読みやすい説明PDFを作れます。

- MIT
- Apache-2.0
- BSD-3-Clause
- MPL-2.0
- LGPL-3.0
- GPL-3.0
- AGPL-3.0

標準OSSライセンスへ独自条件を混ぜることはせず、許可・条件・制限と参照先を表示します。

## PDF

標準では次のような構成になります。

1. 表紙
   - タイトル
   - 作品名
   - 作者名
   - 更新日
   - アップロードしたイラスト / 画像
2. 利用条件
   - 「できること / 要相談 / 禁止」のサマリー
   - 用途別マトリクス
   - クレジット
   - 禁止事項
   - 補足
3. 詳細ページ（必要な場合のみ）
   - 長い補足
   - 独自条項
   - 問い合わせ先

## GitHub Pages

1. **Settings** → **Pages** を開く
2. Source で **Deploy from a branch** を選ぶ
3. `main` / `/ (root)` を指定
4. 保存

## 技術

- HTML / CSS / Vanilla JavaScript
- html2canvas
- jsPDF
- LocalStorage
- FileReader API

サーバー側処理はありません。入力した作品情報や表紙画像は、通常は利用者のブラウザ内で処理されます。

## 注意

このアプリは利用条件を**分かりやすく整理・表示するためのツール**です。法的助言を提供するものではありません。

特に独自規約を重要な商取引や契約に使う場合は、必要に応じて専門家へ確認してください。Creative CommonsやOSSなどの標準ライセンスについては、PDF内の要約ではなく公式ライセンス本文が優先されます。
